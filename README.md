# Netflix Content & Demographic Strategy Analysis

## Project Overview
This project delivers an interactive Power BI dashboard designed to evaluate Netflix's content catalog. By transforming and visualizing raw catalog data, the report uncovers core business strategies around audience targeting, content formats, and global acquisition.

## Strategic Insights
* Target Demographic: Overwhelmingly skewed toward Adults and Teens. Content rated TV-MA and R accounts for over 5,500 titles, while TV-14 represents the second-largest segment. Dedicated children's content represents a minor fraction of the catalog.
* Format Dynamics: Feature films follow a standard runtime distribution of 90–100 minutes. TV series heavily favor single-season runs, pointing to an acquisition strategy focused on volume and rapid turnaround.
* Geographic Expansion: The United States and India dominate total volume, while South Korea and Japan represent key international growth hubs.

## Tech Stack & Skills
* Business Intelligence: Power BI Desktop (DAX, Data Modeling, Custom Visualizations)
* Data Transformation: Power Query
* Visuals & UX: Treemaps, Global Toggles, Dynamic Slicers, and Button-Based Page Navigation
